# EnL-Texture_Pack_Project-Bedrock

Resource packs live under `development_resource_packs/`. Choice Textures is the realm base layer (`CHOICE_PACK.md`). Overlay packs stack above it.

| Pack | Folder | Role |
|---|---|---|
| Choice Textures | `Choice Textures_rp/` | Base blocks, items, mobs, and UI |
| Choice Mobs & UI | `Choice_Mobs_UI/` | Choice mobs, clock, compass, and UI only. Stack above any other pack. Spawn eggs are not included. Natural animal art in it is private Marketplace art. See that folder's README. |
| Animation Essentials | `Animation_Essentials/` | Mob animations. Replaces client entity files and ships its own mob textures. |
| Animation Extended | `Animation_Extended/` | Allay, creeper, evoker, polar bear, and vex animations. |
| Conquest Lite | `Conquest_Lite_RP/` | Conquest Lite blocks and items |
| Bonus Blocks | `els_bb/` | Extra decorative blocks |
| Mob Mod | `mob_mod_resource_pack/` | Enderman and drowned behavior-facing textures |
